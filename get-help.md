# Getting help and support with Paver
{: #help-and-support}

If you experience an issue or have questions, you can ask Paver, submit feedback, or troubleshoot CLI installation.
{: shortdesc}

Paver can help you understand its capabilities, available commands and their usage, and how to troubleshoot issues that arise. If you get to a point where you need additional support, just ask Paver. Based on your [support plan](/docs/support?topic=support-support-plans), you can work with Paver to open a support case or connect with a live support engineer.

## Ask Paver with `paver chat`
{: #paver-chat}

The fastest way to get help is to ask Paver directly. Start an interactive session by running the following command:

```sh
paver chat
```
{: pre}

From the `paver chat` session, you can ask Paver about anything, from CLI help and command syntax to understanding how specific features work. For a full list of available commands, use the built-in help:

```sh
paver help
```
{: pre}

For detailed information about a specific command, run:

```sh
paver help [command]
```
{: pre}

## Submitting feedback in Paver
{: #paver-feedback}

Your feedback is valuable in helping the Paver team improve the experience. Submit feedback directly from a `paver chat` session:

```sh
/feedback "Your feedback message here"
```
{: pre}

The following examples show helpful feedback messages:

```sh
/feedback "Successfully automated a complex deployment workflow"
```
{: pre}

```sh
/feedback "Encountered difficulty with resource provisioning commands"
```
{: pre}

When you submit feedback, relevant logs and diagnostic data are automatically sent for analysis.
{: note}
